# cheese-clip

치지직 방송을 단축키 하나로 **WebP · MP4 · 스크린샷**으로 저장하는 크롬 확장 프로그램

## 주요 기능

* **WebP · 영상 즉시 저장** — 방금 지나간 장면을 단축키 한 번으로 저장 (WebP 최대 15초, 영상 최대 60초, 소리 포함)
* **스크린샷** — 방송 화면을 캡쳐하고, 저장할지 닫을지 선택
* **녹화** — 이미 담긴 장면에 이어서 최대 10분. 끝나면 바로 편집 화면
* **편집** — 시작·끝 지정, 화면 자르기, WebP 배속, 소리 싱크 조절, 현재 장면 스크린샷
* **교차편집** — 여러 방송(최대 5개)을 한 영상으로 전환 편집, 소리로 자동 싱크
* **재생바 버튼** — 치지직 재생바에 스크린샷·녹화 버튼
* **음소거해도 녹음** — 플레이어를 음소거해도 소리는 계속 저장
* **플레이어 화질 1080p 고정** — 치지직이 화질을 낮춰도 저장 화질 유지

## 설치

1. 위의 **최신 버전 받기**에서 `cheese-clip-vX.X.X.zip`을 받아 압축을 풉니다. 풀린 폴더는 지우거나 옮기지 않습니다.
2. 크롬 주소창에 `chrome://extensions` → **개발자 모드** 켜기 → **압축해제된 확장 프로그램을 로드합니다** → 풀린 폴더 선택
3. 치지직 탭을 새로고침합니다.

**업데이트**: 같은 폴더에 새 파일을 덮어쓰고, `chrome://extensions`에서 새로고침(↻)합니다.

## 시작하기

1. 치지직 방송에서 확장 아이콘을 눌러 그 채널의 **WebP** · **영상** 스위치를 켭니다. (채널마다 따로 설정)
2. 몇 초 지나면 단축키로 저장할 수 있습니다.
3. 화질, 저장 길이, 저장 위치 등은 팝업의 **⚙ 설정**에서 바꿉니다.

## 기본 단축키

|키|기능|
|-|-|
|`Ctrl+Shift+S`|WebP 저장|
|`Ctrl+Shift+F`|영상 저장|
|`Ctrl+Shift+E`|편집|
|`Ctrl+Shift+X`|교차편집|
|`S`|스크린샷|
|`R`|녹화 시작 / 종료|

## 편집 · 교차편집

|기능|사용법|
|-|-|
|범위 지정|초록 표시 끌기, `I` / `O`, **지금부터 5·10·15초** 버튼|
|저장 형식|**영상 / WebP** 토글. WebP는 1~4배속 가능|
|화면 자르기|자유 · 16:9 · 9:16 · 1:1 · 4:3. **잘라낸 크기**(용량 작음) / **고른 크기에 맞춤** 선택|
|소리 싱크|소리가 빠르면 +, 느리면 − (최대 ±5초)|
|현재 장면 저장|**📷 현재 장면** 또는 `P` — 원본 해상도 PNG|
|교차편집 전환|`1`~`5` 키로 그 순간부터 해당 방송으로|

예상 용량이 미리 표시되며, WebP 20MB · 영상 50MB를 넘으면 노란색으로 바뀝니다.

## 저장 위치

```
다운로드/cheese-clip/스트리머명/방송제목｜날짜/
  ├ mp4/
  ├ webp/
  └ screenshot/
```

* 파일 이름: `[스트리머명｜방송제목] yy-mm-dd hh：mm：ss.확장자`
* 설정에서 다운로드 폴더 밖의 폴더나 채널별 폴더를 고를 수 있습니다.

## 문제 해결

|증상|해결|
|-|-|
|움직임이 많은 장면이 뭉개짐|설정 → 영상 → 압축 품질 **최고**|
|소리가 화면보다 빠르거나 느림|설정 → 소리 싱크 보정, 또는 편집 화면의 소리 싱크|

그 밖의 문제는 [Issues](https://github.com/llamochang2/cheese-clip/issues)에 팝업 상태 줄의 내용과 함께 남겨 주세요.

## 개인정보

* 권한은 `storage` · `downloads` · `offscreen`만 사용하며, 페이지 접근은 `chzzk.naver.com`으로 한정됩니다.
* 외부로 보내는 정보는 스트리머 이름·방송 제목 조회(치지직 API)뿐이며, 수집·공유 기능은 없습니다.

## 이용 안내 및 면책

* 개인적인 감상·소장 목적의 비공식 도구이며, NAVER Corp. 및 치지직(CHZZK)이 제작·운영하거나 승인한 것이 아닙니다. 치지직(CHZZK)의 명칭과 서비스에 관한 권리는 NAVER Corp.에 있습니다.
* 저장한 영상·이미지의 저작권은 해당 스트리머와 원저작자에게 있습니다. SNS·커뮤니티·영상 플랫폼 등에 올리거나 공유하려면 반드시 스트리머의 허락을 받고, 스트리머가 정한 2차 창작·클립 규정을 따라야 합니다.
* 영리 목적 사용, 무단 재배포, 편집 후 재업로드 등은 저작권법 위반이 될 수 있습니다.
* 이 도구를 사용해 생긴 저작권 침해 및 분쟁의 책임은 사용자에게 있으며, 제작자는 책임지지 않습니다. 치지직 이용약관을 지켜서 사용해 주세요.
